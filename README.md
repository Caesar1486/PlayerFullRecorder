# PlayerFullRecorder
一款专为 Nukkit-MOT 开发的全覆盖玩家行为记录插件。通过原生事件+数据包监听，完整记录玩家所有服务器行为，包含：全部聊天内容、执行指令、方块放置/破坏/点击、容器开箱与物品移动、背包操作、实体交互、物品拾取丢弃、投掷物、传送、死亡复活等全维度操作。 所有监听功能支持配置文件独立开关与一键全开，日志同步输出至服务端后台，并按日期自动分割保存本地日志文件，方便违规溯源与服务器安全审计。 内置TPS性能保护机制，服务器低负载时自动限流，避免卡顿。插件无前置依赖、开箱即用、支持配置热重载。 ⚠️合规提示：使用前需告知玩家全程行为记录，仅用于服务器管理与反作弊用途。
